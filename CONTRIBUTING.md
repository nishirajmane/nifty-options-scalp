# Contributing

Open an issue to describe a proposed change or submit a pull request with the changed skill files. Keep claims about profitability separate from rules that have only been proposed.

For a strategy change, include the exact entry and exit rules, data source and dates, number of trades, net results after realistic fills and costs, out-of-sample results, and failure cases. Note whether the data uses the index, futures, or actual option quotes. Please avoid posting account details, broker credentials, or proprietary data without permission.

For wording or usability fixes, explain the situation that was confusing and how the edit resolves it. Run the Codex skill validator if available before submitting.
